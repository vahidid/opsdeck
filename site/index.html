Your infrastructure,
one workbench.

Servers, VPNs, containers, clusters and logs from one local app, with an AI agent that works through the same tools and asks before it changes anything.

Download opsdeck
Windows · macOS · Linux · free and open source (MIT)

Everything you reach for, in one place

Workspaces keep a project's hosts, networks, clusters and docs together as plain YAML and Markdown — git-friendly, and never with secrets in them.

SSH that just reaches

Terminals, remote files, host stats and live logs. Jump hosts and VPNs come up on their own when a host sits behind them.

Every kind of VPN

WireGuard, Tailscale/Headscale, NetBird, OpenVPN, AnyConnect, FortiGate, GlobalProtect and more, many at once without root, with single sign-on.

Docker & Kubernetes

Containers, Compose, Swarm and volumes; every Kubernetes resource with logs, exec, rollouts, Helm and apply with a server-side diff.

Git, Ansible and scripts

Repositories with merge requests, an Ansible editor with visual views and Ansible Vault, and a reviewed script library that runs on hosts.

An encrypted vault

SSH keys, logins with TOTP, tokens, kubeconfigs and VPN configs, encrypted locally. opsdeck uses them; the agent never sees them.

An agent with approvals

Any model — Anthropic, OpenAI-compatible, Ollama — or your Claude Code, Codex or Gemini CLI login. Changes are previewed and approved.

Know how it all connects

A topology map per workspace: zones, routers, firewalls, load balancers, servers and what runs on them. The agent reads it and proposes changes for you to approve.

  • Safe by default — every tool call is classified as read, change or destructive, and changes on servers ask first in every mode.
  • Secrets stay out — vault values are redacted from everything the model sees.
  • Accountable — a hash-chained audit journal of every action, by you or the agent.
  • Local-first — it runs on your computer and listens only on 127.0.0.1.

Install

Download the app, or let the script pick the right file and check its checksum. Once installed, opsdeck updates itself from inside the app.

Windows

Windows 10/11, x64
irm https://vahidid.github.io/opsdeck/install.ps1 | iex

macOS

macOS 12+, Apple silicon and Intel
curl -fsSL https://vahidid.github.io/opsdeck/install.sh | sh

Linux

.deb and .rpm, x86_64
curl -fsSL https://vahidid.github.io/opsdeck/install.sh | sh

Only want the CLI (opsdeck serve, the UI in your browser)? Add -s -- --cli to the script, or pick opsdeck-cli-… from the release. The builds are not code-signed yet: on macOS, right-click the app and choose Open the first time; on Windows choose More info → Run anyway.
